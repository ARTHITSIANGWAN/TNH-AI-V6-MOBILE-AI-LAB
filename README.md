## 🛡️ Security Architecture: The Snake Nudge Protocol
เราสร้าง "สัจจะ" ในการปกป้องข้อมูล SME ด้วยเลเยอร์ที่คมกริบ:

* **Dark-Relay Authentication:** ระบบส่งต่อข้อมูลแบบ Stateless ไร้รอยต่อ ลดจุดเสี่ยง Man-in-the-middle
* **Snake Nudge HMAC:** เข้ารหัส **HMAC-SHA256** ทุก Request ยืนยันว่าคำสั่งมาจาก "หัวใจ" ของเจ้าของจริง
* **Zero-Garbage Engine:** รัน Go บน Mobile 24/7 โดยไม่เกิด Memory Leak ไม่ต้องพึ่งพา PC
